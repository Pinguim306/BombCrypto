Semantics:
- **Poll loop**: `while gen == _gen and phase in [LOADING, LIVE, DEGRADED, OFFLINE]: if _hidden or not _online: await _resume_signal; seq := ++_seq; _inflight = true; env := await Backend.state(); _inflight = false; if gen != _gen: return; _handle_poll(env, seq); await create_timer(_next_delay()/1000.0).timeout`. One-shot re-armed ⇒ never overlapping. `_gen += 1` on every stop/restart.
- **Sequencing**: `_apply(dict, seq)` ignores `seq < _applied_seq`; mutations run through `_run` which suspends the loop (`busy`) and re-arms it with a full `poll_ms` after the mutation's fresh DTO is applied (no redundant SQLite write).
- **Failure policy**: ok → `_failures=0`, LIVE, apply. `code=="session_expired"` → `_gen+=1`, SESSION_EXPIRED, `status("error: session expired", KEEP)`, `Backend.nav("login")`. Else `_failures+=1`; DEGRADED (1-2) / OFFLINE (≥3); `status("error: "+env.error, KEEP)` (Phaser parity) + `net_changed` (banner "connection problem — retrying in Ns"); delay `BACKOFF_MS[min(_failures,4)] + randi_range(0,250)`; last good state kept on screen.
- **Parse failure**: `StateModel.parse` null → treated as failed poll, `status("error: bad state from server", ERROR)`, `push_error(StateModel.last_error)`.
- **Host events**: `visibility hidden` → `pause()` (HIDDEN, `Fx.set_active(false)`); `hidden:false` → `resume()` + `refresh_now()`. `online:false` → OFFLINE immediately (no request, delay 5 s); `online:true` → `_failures=0`, `refresh_now()`. `session loggedIn:false` → SESSION_EXPIRED (reason expired) or LOGGED_OUT (reason disconnect); `loggedIn:true` → `on_logged_in()`. `nav` → ignored for `play|mining`; other targets are handled by the host itself. `NOTIFICATION_APPLICATION_FOCUS_IN` → `refresh_now()` (backup).
- **Actions** (`_run`): if `busy` → `status("please wait…", NEUTRAL)`; `busy=true`; `seq := ++_seq`; `env := await fn.call()`; `if not is_inside_tree(): return`; `busy=false`; if `env.ok and env.data is Dictionary and env.data.has("heroes")` → `_apply(env.data, seq, name)`. Status texts exactly per brief §14-16/§19: `set_hero_mode` ok → `status("", KEEP)`, error → `"error: <m>"` KEEP; `toggle_house`: housed → `set_house(id,"")`, else `free_house()` or `status("no house with a free slot", KEEP)` without request; `mine_all`: disable button → `Fmt.mine_all_msg(int(data.changed))` SUCCESS / `"error: <m>"` ERROR → re-enable; `go_adventure`: `"expedition in progress..."` NEUTRAL → `_apply(data.state)` → victory SUCCESS / defeat ERROR / `"adventure: <m>"` ERROR; `claim`: `"issuing voucher..."` NEUTRAL → `Backend.claim(false)` → on `claim_progress("wallet")` `"confirm the claim transaction in your wallet..."` → ok `"claim sent: <hash>"` SUCCESS (status text becomes clickable → `Backend.open_explorer(hash)` from the click callback) / error `"claim failed: <m>"` ERROR → `refresh_now()`.
- **Daily badge**: `daily_status()` on LIVE entry, on `resume()`, every `DAILY_REFRESH_MS`; `daily_badge_changed(bool(data.canClaim))`.
- `selected_stage` persists for the page session (Phaser parity), reset to 0 on SESSION_EXPIRED/LOGGED_OUT.

## 8. GDScript wrapper (`scripts/backend/web_backend.gd`) incl. promise→callback mechanism

```gdscript
class_name WebBackend extends BackendBase
var _mb: JavaScriptObject
var _cb: JavaScriptObject          # ONE persistent callback for all invoke results — must stay referenced for the whole session (GC guard, verified)
var _listener: JavaScriptObject    # persistent host→Godot listener
var _pending: Dictionary = {}      # req_id:String -> Pending
var _seq := 0
class Pending extends RefCounted:
    signal done(env: Envelope)

static func available() -> bool:
    return OS.has_feature("web") and JavaScriptBridge.eval("typeof window.mb === 'object' && window.mb.version === 1", true) == true

func _ready() -> void:
    _mb = JavaScriptBridge.get_interface("mb")            # requires a real window.mb property (verified)
    _cb = JavaScriptBridge.create_callback(_on_result)
    _listener = JavaScriptBridge.create_callback(_on_host_event)
    _mb.setListener(_listener)                             # host replays {"type":"session",...} immediately

func _invoke(method: String, args: Dictionary = {}, timeout_ms: int = Config.REQUEST_TIMEOUT_MS) -> Envelope:
    _seq += 1
    var id := "%d" % _seq
    var p := Pending.new(); _pending[id] = p
    _mb.invoke(id, method, JSON.stringify(args), _cb)      # returns immediately; JS resolves the Promise then calls _cb(reqId, envelopeJson)
    get_tree().create_timer(timeout_ms / 1000.0).timeout.connect(func():
        if _pending.has(id): _pending.erase(id); p.done.emit(Envelope.fail("timeout", method + " timed out")))
    return await p.done

func _on_result(a: Array) -> void:                          # a[0]=reqId String, a[1]=envelope JSON String (JS args arrive as ONE Array)
    var p: Pending = _pending.get(a[0]); if p == null: return   # late/duplicate → ignored
    _pending.erase(a[0])
    var env := Envelope.from_json(a[1])
    if not env.ok and env.code == "session_expired": host_event.emit({"type": "session", "loggedIn": false, "reason": "expired"})
    p.done.emit(env)

func _on_host_event(a: Array) -> void:
    var ev: Variant = JSON.parse_string(a[0])
    if typeof(ev) == TYPE_DICTIONARY: host_event.emit(ev)

func state() -> Envelope: return await _invoke("apiState")
func set_mode(hero_id: String, mode: String) -> Envelope: return await _invoke("apiSetMode", {"heroId": hero_id, "mode": mode})
func set_team_mode(mode: String) -> Envelope: return await _invoke("apiSetTeamMode", {"mode": mode})
func set_house(hero_id: String, house_id: String) -> Envelope: return await _invoke("apiSetHouse", {"heroId": hero_id, "houseId": house_id})
func adventure(hero_id: String, stage_id: int) -> Envelope: return await _invoke("apiAdventure", {"heroId": hero_id, "stageId": stage_id})
func daily_status() -> Envelope: return await _invoke("apiDailyStatus")
func claim(wait_receipt: bool) -> Envelope: return await _invoke("claim", {"waitForReceipt": wait_receipt}, Config.CLAIM_TIMEOUT_MS)
func connect_wallet(kind: String) -> Envelope: return await _invoke("connect", {"kind": kind}, Config.CLAIM_TIMEOUT_MS)
func sign_in() -> Envelope: return await _invoke("signIn", {}, Config.CLAIM_TIMEOUT_MS)
func reconnect() -> Envelope: return await _invoke("reconnect")
func disconnect() -> Envelope: return await _invoke("disconnect")
func config() -> Dictionary: return JSON.parse_string(_mb.configJson())
func session() -> Dictionary: return JSON.parse_string(_mb.sessionJson())
func notify_ready() -> void: _mb.ready()
func nav(t: String) -> void: _mb.nav(t)
func open_explorer(h: String) -> void: _mb.openExplorer(h)   # call only from an input callback (window.open needs user activation)
```
Type rules (verified): args crossing to JS must be primitives (Dictionary → `undefined`), hence JSON strings; JS numbers → int/float, strings → String, objects → JavaScriptObject; `JSON.parse_string` makes every number float → cast with `int()`; wei/nonce/ids/pendingBlast stay strings. Only `web` feature builds touch `JavaScriptBridge`; in the editor `available()` is false.

# Appendix A — window.mb bridge contract

# `window.mb` — host-page bridge contract (MinerBlast v2, Godot 4.7.2 Web)

Implemented in `client/src/bridge/mb.ts` (+ `client/src/bridge/envelope.ts`), installed by `client/src/play2.ts` as a real `window.mb` property BEFORE `Engine.startGame()`. Reuses `client/src/net/api.ts` and `client/src/web3/wallet.ts` unchanged. Godot obtains it with `JavaScriptBridge.get_interface("mb")`.

## Conventions
1. Every value crossing the bridge is a primitive (`string | number | boolean`) or a JS function (callbacks). Objects cross as JSON strings.
2. GDScript uses ONE async entry point, `invoke(reqId, method, argsJson, cb)`. `cb` is called exactly once, asynchronously (`Promise.resolve().then(...)`), even on synchronous throws, with an envelope JSON string. It never rejects, never throws into Godot.
3. Envelope: `{"ok":true,"data":<T>}` or `{"ok":false,"error":"<message>","code":"<MbErrorCode>"}`.
4. Numbers that must stay exact (`amount`/`amountWei` wei, `nonce`, `pendingBlast`, `rewardBlast`, ids, hashes) are JSON strings. Godot's `JSON.parse_string` turns every JSON number into float.
5. Host → Godot pushes go through the single listener set by `setListener(cb)` (last wins); `setListener` immediately replays the latest `session` event.
6. Sync getters return JSON strings synchronously.

## TypeScript surface
```ts
type MbErrorCode =
  | "session_expired"        // api.ts 401 → Error("session expired"); also emits listener {"type":"session","loggedIn":false,"reason":"expired"}
  | "user_rejected"          // viem UserRejectedRequestError or provider code 4001
  | "no_wallet"              // message starts "No wallet found"
  | "wallet_not_connected"   // "wallet not connected"
  | "wrong_chain"            // message contains "Robinhood Chain" (wallet.ts ensureChain errors)
  | "mobile_unavailable"     // "Mobile wallet is not configured yet."
  | "network"                // TypeError "Failed to fetch" | "NetworkError" | "Load failed"
  | "http"                   // any other server body.message or /^HTTP \d+$/
  | "voucher_chain_mismatch" // voucher.chainId !== CHAIN_ID (client-side check, no tx sent)
  | "receipt_timeout"        // waitForClaim timeout (240 s)
  | "reverted"               // receipt.status !== "success"
  | "unknown";
// error text = (e.shortMessage ?? e.message ?? String(e)).split("\n")[0].slice(0, 120)
// (server strings such as "minimum claim is 30,000 BLAST", "claim cooldown active — try again in ~37 min",
//  "insufficient stamina", "house is full", "daily adventure limit reached" pass through verbatim)

type Envelope<T> = { ok: true; data: T } | { ok: false; error: string; code: MbErrorCode };

interface MbBridge {
  readonly version: 1;

  // ---- sync ----
  configJson(): string;
  // {"serverUrl":string,"chainId":4663,"rpcUrl":string,"explorerUrl":string,"vaultAddress":string,

  //  mock = URL has ?mock=1 ; reducedMotion = matchMedia("(prefers-reduced-motion: reduce)").matches ; buildId = manifest.gitSha

  // {"hasToken":boolean,"tokenAddress":string|null,"walletAddress":string|null,
  //  "walletKind":"injected"|"walletconnect"|null,"loggedIn":boolean}
  //  loggedIn = hasToken && (walletAddress == null || walletAddress.toLowerCase() == tokenAddress.toLowerCase())

  // ---- the one async entry point used by GDScript ----
  invoke(reqId: string, method: MbMethod, argsJson: string,
         cb: (reqId: string, envelopeJson: string) => void): void;
  // argsJson is ONE JSON object (may be "{}" or ""); invoke does JSON.parse(argsJson || "{}") and calls mb[method](args).
  // Unknown method → {"ok":false,"error":"no such bridge method: <m>","code":"unknown"}.

  // ---- async methods (dispatched by invoke; also usable by the page; each takes ONE args object) ----
  connect(a: { kind: "injected" | "walletconnect" }): Promise<{ address: string }>;
  signIn(a: {}): Promise<{ address: string }>;
  reconnect(a: {}): Promise<{ walletAddress: string | null; tokenAddress: string | null; loggedIn: boolean; mismatch: boolean }>;
  disconnect(a: {}): Promise<{}>;
  apiState(a: {}): Promise<GameStateDto>;
  apiSetMode(a: { heroId: string; mode: "work" | "rest" }): Promise<GameStateDto>;
  apiSetTeamMode(a: { mode: "work" | "rest" }): Promise<GameStateDto & { changed: number }>;
  apiSetHouse(a: { heroId: string; houseId: string }): Promise<GameStateDto>;      // "" → null (leave house)
  apiAdventure(a: { heroId: string; stageId: number }): Promise<AdventureResultDto>;
  apiDailyStatus(a: {}): Promise<DailyStatusDto>;
  apiVoucher(a: {}): Promise<VoucherDto>;                                          // debits pending server-side
  claim(a: { waitForReceipt: boolean }): Promise<{ hash: string; amountWei: string; receipt: "success" | "reverted" | "timeout" | "not_awaited" }>;

  // ---- Godot → host, sync void ----
  ready(): void;                       // Godot main scene up: hide #loader; show #connect-overlay if !loggedIn
  nav(target: string): void;           // "login" → show overlay; "play"|"mining" → no-op; anything else → location.href = "/"
  openExplorer(hash: string): void;    // window.open(`${EXPLORER_URL}/tx/${hash}`, "_blank", "noopener")
  setListener(cb: (jsonEvent: string) => void): void;   // single listener, last wins; replays last {"type":"session"} immediately
}
```

## `invoke` implementation
```ts
invoke(reqId, method, argsJson, cb) {
  Promise.resolve()
    .then(() => {
      const f = (window.mb as any)[method];
      if (typeof f !== "function" || !METHODS.has(method)) throw new Error(`no such bridge method: ${method}`);
      return f.call(window.mb, JSON.parse(argsJson || "{}"));
    })
    .then((data) => cb(reqId, JSON.stringify({ ok: true, data: data ?? null })),
          (e) => { const m = mapError(e); if (m.code === "session_expired") emit({ type: "session", loggedIn: false, reason: "expired" }); cb(reqId, JSON.stringify({ ok: false, ...m })); });
}
```

## Error strings the host may surface (verbatim)
Wallet: `wallet not connected`, `No wallet found. ## Ordering guarantees
`window.mb` (and `__mbTestOverrides` merge) is installed before the engine script is injected and before `Engine.startGame()`; Godot's `_ready()` runs only after `callMain`, so `get_interface("mb")` succeeds. `setListener` replays the current session so a login that finished before Godot booted is not missed. `ready()` may be called before or after `reconnect()` resolves; the host handles both orders.
